英会話ラボ　公開・運用マニュアル（運営者向け）

AIの話し相手と声だけで英会話を練習できる Web アプリです。 このマニュアルは、アプリを公開・更新・管理する運営者向けです。利用者向けの説明は、アプリの中の「使い方」（public/guide.html）にあります。

1. 商品の概要

項目 内容
商品名 英会話ラボ（Eikaiwa Lab）
形態 Web アプリ（URL を開くだけ。インストール不要。パソコン・スマホ対応）
主な機能 英語ゼロから始める8ステップのレッスン／つっかえ・長い沈黙に配慮した聞き取り／小さな声・ささやき声と雑音への対応（声の登録）／大げさにほめるごほうび／AIとのリアルタイム音声会話（話し相手5人）／会話後のおさらい・言い直し練習・音読・間隔をあけた復習

3. 初めて公開する

Windows の場合です。Node.js（LTS版）が入っている必要があります。

  1. このフォルダを開き、エクスプローラーのアドレスバーに cmd と入力して Enter（黒い画面が開く）。
  2. 1行ずつ入力して Enter。 npm install -g netlify-cli npm install netlify login netlify sites:create --name 好きな名前 netlify env:set GEMINI_API_KEY あなたのAPIキー netlify env:set PASSCODE 合言葉 netlify env:set ADMIN_PASSWORD 管理パスワード netlify deploy --prod
  3. 最後に表示される https://好きな名前.netlify.app が公開URLです。

注意 - 選択式の質問（矢印キーで選ぶもの）は黒い画面でずれることがあるので、上のように名前を指定する方法で進めてください。 - 黒い画面の中をクリックすると「選択」モードになり、処理が止まります。Esc で解除できます。 - APIキーを入力した画面は、スクリーンショットで人に送らないでください。cls で表示を消せます。

この章は「新しくサイトを作る」ときの手順です。すでにあるサイトを更新するときは 4 章だけを使ってください。 1行入力するごとに Enter を押してください（まとめて貼り付けると動きません）。

4. 更新する（ファイルを差し替えたあと）

フォルダで黒い画面を開き、次の1行だけです。

netlify deploy --prod

利用者には「Ctrl + F5 で再読み込み」してもらうと、すぐ新しい版になります。

6. 利用コードで販売する

コードを発行する

  1. https://あなたのサイト/admin.html を開き、管理パスワードでログインします。
  2. プランを選びます（7日体験／30日パス／90日パス／団体・教室用／自分で決める）。
  3. 購入者の名前やメモ（例：「山田さん note 10/14購入」）を入れて「発行する」。

  4. 下に購入者への案内文（アプリのURL・利用コード・プラン）が出るので、「案内文をコピー」してメールやDMで送ります。

  5. 有効日数は、購入者が最初に使った日から数えます。

  6. 教室や会社には「発行する数」を人数分にして、名前に団体名を入れます。生徒1人に1つずつ配ってください。

発行したコードを管理する

  • 一覧で、状態（未使用・利用中・期限切れ・停止中）、有効期限、今日の利用回数がわかります。
  • +30日：期限を30日延ばします（延長の購入があったとき）。
  • 停止／再開：返金や不正利用のときに止められます。止めたコードはすぐ使えなくなります。
  • 削除：2回押すと消えます。元に戻せません。
  • CSVで保存：一覧を Excel で開ける形で保存できます。

販売の流れ（例）

  1. Stripe の支払いリンク・note・BOOTH などで「30日パス」を販売します。
  2. 購入の通知が来たら、管理画面でコードを1つ発行し、案内文を購入者に送ります。
  3. 期限が近い人に延長を案内し、購入があれば「+30日」。

紹介ページを書き換える

public/index.html の上のほうにある CONFIG を書き換えて、netlify deploy --prod で反映します。

項目 入れるもの 入れるとどうなるか
purchaseUrl 決済ページのURL 「購入する」ボタンがそのページにつながる
monitorUrl モニター申込先（Xのプロフィール、Googleフォームなど） 「無料モニターに申し込む」ボタンがつながる
contactUrl 問い合わせフォームのURL、または mailto:アドレス 団体向けの問い合わせボタンとフッターのリンクが出る

7. 日々の管理

  • 管理パスワードを変える：netlify env:set ADMIN_PASSWORD 新しいパスワード → netlify deploy --prod。
  • 合言葉を変える：netlify env:set PASSCODE 新しい合言葉 → netlify deploy --prod。古い合言葉はすぐ使えなくなります。
  • APIキーを替える（漏れたかもしれないとき）：Google AI Studio で古いキーを削除 → 新しいキーを作る → netlify env:set GEMINI_API_KEY 新しいキー → netlify deploy --prod。
  • 利用回数を見る：Netlify の管理画面 → このプロジェクト → Blobs → usage に日付ごとの回数があります。
  • うまく動かないとき：Netlify の管理画面 → Logs → Functions で、サーバー側のエラーを確認できます。

8. 販売を始める前に必ず確認すること

利用コードの仕組みはできていますが、決済は外部のサービス（Stripe・note・BOOTHなど）を使い、コードは管理画面から手で送る形です。販売を始める前に、次を整えてください。

  1. Gemini API を有料プランにする：無料枠は回数の上限が低く、送った内容が Google のサービス改善に使われる条件があります。お金をいただく商品では有料プランが前提です。あわせて Google Cloud で予算アラートを設定してください。
  2. 原価を計算する：有料プランでは、会話の長さに応じて料金がかかります。テスト期間に、1人が1回（10〜15分）使ったときの料金を Google Cloud の請求画面で確認し、価格を決めてください。
  3. 利用規約・プライバシーポリシー：音声を外部のAI（Google）に送ることを明記してください。
  4. 特定商取引法に基づく表記：有料で販売する場合、販売者名・連絡先・価格・返金条件などの表示が必要です。
  5. 販売の窓口を決める：Stripe の支払いリンク・note・BOOTH など。決まったら紹介ページの CONFIG に入れる（6章）。
  6. 将来、購入と同時にコードが自動で届く仕組みや、会員登録・月額課金も追加できます（別途開発）。
  7. 商品名の確認：「英会話ラボ」と似た名前の商標がないか、販売前に確認してください。

法律・規約の内容は、必要に応じて専門家に確認してください。

9. 対象の人に合わせた作り（ゼロから・吃音・小さな声）

アプリを開くと最初に「レッスン」タブが出ます。

対象 アプリの動き 設定
英語の知識がほぼゼロ 6レベル・23ステージ（はじめの一歩／じぶんのこと＝be動詞／うごきのことば＝一般動詞／たずねることば＝疑問詞／いま・きのう・あした＝時制／つかえる表現）。各ステージのはじめに文のしくみを日本語で説明し、単語ごとの意味とカタカナの読み方つき。1つのことばを「聞く → いっしょに言う → ひとりで言う」の順に練習。英語を少し知っている人は、レベル選びか「かんたんチェック」で途中から始められる レベル「はじめて」が初期値。会話タブでもAIがやさしい英語で話し、困ったら日本語で助け舟を出す
発話障害（吃音など） 話し始めるまで時間の制限なし。話し終わりは「3秒だまったら」が初期値で、5秒・8秒・「言い終わった」ボタンも選べる。くり返し・のばし・沈黙・言い直しは採点に入れず、AIも触れない。会話の相手は割り込まず、先回りもしない 「話し終わりの合図」「つっかえ・沈黙への配慮」
小さな声・ささやき声・にぎやかな場所 30秒の「声の登録」で声の大きさと響きを記録し、マイクの感度を自動で合わせる。まわりの音を常に測り、それより目立つ声だけを「話した」とみなす。送る音声は聞き取りやすい大きさにそろえる 「マイクの感度」「登録した声だけ拾う」「ブラウザの雑音カット」
続ける力 言えたら高い声の英語と日本語でほめ、効果音と紙ふぶき。がんばりスタンプと、続けた日数を表示 「ほめ方」（大げさに／ふつう／しずかに）

説明するときの注意 - 「声の登録」は、声の大きさと響きの形で見分ける簡易的な仕組みです。特定の人の声だけを確実に聞き分ける「話者識別」ではありません。すぐ近くで別の人がはっきり話していると拾うことがあります。にぎやかな場所では、マイクつきイヤホンをすすめてください。 - 吃音への配慮は「練習を妨げない」ためのもので、治療や訓練の効果をうたうことはできません。紹介ページでもそう書いています。 - ささやき声には声の高さがないため、イントネーション（抑揚）は判定しません。

進み具合の保存（つづきの合言葉）

  • 利用者が「ここまで保存」を押すか、声で「セーブ」と言うと、進み具合・スター・復習リスト・声の登録・設定を Netlify Blobs の progress に保存し、8文字の合言葉を返します。
  • 合言葉を入れると、別の端末でも続きから始められます。保存できるのは、利用コードか合言葉（モニター用）が正しい人だけです。回数の上限には数えません。
  • 総当たり対策：合言葉の読み込みは、1回線あたり1日30回まで間違えられます。保存は1回線あたり1日300回まで。

チャレンジ・コイン・きせかえ

  • 「チャレンジ」タブ：英語の質問（ランクごとに5問×8ランク）に声で答える。制限時間なし。通じればコイン（5＋ランク×5）、3問でランクアップ（ボーナス ランク×20コイン）。
  • コインはほかに、レッスンで言えた（3）・チャレンジした（1）・ステージクリア（10）・レベルクリア（50）・会話で1回話す（1）でたまる。
  • 「きせかえ」：髪型88通り、架空ブランド12 × アイテム31種類 ＝ 372アイテム。コイン・持ち物・アバターは「つづきの合言葉」でいっしょに保存される。
  • コインは練習のごほうび用で、お金では買えず、お金にも換えられません（課金の仕組みはありません）。
