英会話ラボ 使い方ガイド

英語をまったく知らなくても、Hello から声だけで始められる英会話アプリです。つっかえても、長く黙っても、ささやくような小さな声でも大丈夫。あなたが話すまで、急かさずに待ちます。

はじめに（3ステップ）

STEP 1利用コードを入れる最初に開くと設定が出ます。受け取った利用コード（EL-から始まる12文字）を入れて「確認」。
STEP 2声を登録する（30秒）「レッスン」タブの「声を登録する」を押し、ふだん話す声で「ハロー」と3回。小さな声でも聞き取りやすくなります。
STEP 3スタート地点を決めて、マイクのボタンまったくはじめてなら LEVEL 1 の Hello から。英語を少し知っていれば、途中のレベルからも始められます。

準備するもの

  • ブラウザ：パソコンは Chrome か Edge の最新版。スマホは Chrome（Android）か Safari（iPhone）。
  • マイク：スマホやパソコンのマイクで使えます。初めて使うときにマイクの許可を聞かれるので「許可」を選んでください。
  • マイクつきイヤホン（いちばんおすすめ）：マイクが口の近くにあるので、小さな声でもはっきり入り、まわりの声や音が入りにくくなります。相手の声をマイクが拾ってしまうこともなくなります。
  • 日本語の読み上げ：レッスンでは日本語で説明を読み上げます。スマホやパソコンの「読み上げ音声」に日本語が入っていないときは、説明は画面に表示だけされます。

レッスン（ゼロから）

「レッスン」タブは、6つのレベル・23のステージで、あいさつから文のしくみ（文法）まで、ひとつずつ積み上げていきます。各ステージのはじめに「きょうのポイント」として、文のしくみを日本語で説明します（例：「英語は、わたしは・好き・コーヒー の順番」）。練習する文には、単語ごとの意味も小さく表示されます。

レベルステージ目安
1 はじめの一歩あいさつ／へんじ／こまったとき（Just a moment など）／かず英語はまったくはじめて
2 じぶんのことわたしは〜です（I'm）／あなた・かれ・かのじょ（You are, He is）／これ・あれ（This is）／〜じゃない・〜ですか？あいさつくらいはわかる
3 うごきのことば好き・持っている（I like）／〜しません（I don't）／〜しますか？（Do you）／かれ・かのじょのうごき（likes）中学1年のはじめくらい
4 たずねることばなに？（What）／どこ・いつ・だれ／どう・どのくらい（How）中学1年くらい
5 いま・きのう・あしたいま〜している（-ing）／きのう〜した（went, ate）／〜した？・〜しなかった（Did you）／これから〜する（going to, will）中学2年くらい
6 つかえる表現できる（can）／ていねいなおねがい（I'd like, Could you）／つなぐことば（and, but, because）／ミニ会話1・2中学2〜3年くらい

途中のレベルから始める

はじめて開いたときに「どこから始めますか？」が出ます。英語をある程度知っている人は、レベルを選ぶか、かんたんチェック（例文の意味がわかるかを5問たずねて、おすすめのレベルを出します）で決められます。あとからでも「スタート地点をえらぶ」でいつでも変えられ、とばしたレベルも、上のレベルのボタンからいつでも練習できます。

1つのことばは、次の順に進みます（ステージのはじめには、文のしくみの説明が入ります）。

  1. 聞く：日本語の意味のあと、英語のお手本がゆっくり流れます。画面にはカタカナの読み方も出ます。
  2. いっしょに言う：もう一度お手本が流れるので、声を重ねて言います。ひとりで言うより、ずっと言いやすくなります（設定で外せます）。
  3. ひとりで言う：準備ができたら、どうぞ。話し始めるまで、いつまでも待ちます。

言えたら、効果音と紙ふぶきで、思いきりほめます（設定の「ほめ方」で、ふつう・しずかにも選べます）。2回やってうまくいかなくても「チャレンジ成功」として次へ進み、そのことばは「復習」タブに入って、また出てきます。1つ終えるごとに「がんばりスタンプ」がたまり、続けて使った日数も表示されます。

「もう一回お手本」でお手本を聞き直し、「次のことばへ」でとばせます。声で「もう一回」「スキップ」と言っても大丈夫です。

ほめことばと、ワンポイント

言えたときは、聞こえたよいところ（例：「ハ」の音がとてもきれいでした）を具体的にほめたあと、「〜すると、もっと英語らしくなりますね」というやさしいワンポイントをひとつだけ伝えます。ほめるだけにしたい人は、設定の「やさしいアドバイス」を「伝えない」にしてください。

レベルとスター

ことばを1つ終えるごとにスターが1つ、ステップをクリアするとスターが3つもらえます。スター10こでレベルアップ。画面上の紫のバーで、次のレベルまでの残りと、続けた日数がわかります。ステップの地図では、全部終えたステップが金色、途中のステップが紫になります。

チャレンジ（英語ランク）

「チャレンジ」タブでは、相手が英語で質問し、あなたが声で答えます。制限時間はありません。ひとことでも、だいたい通じればOKです。答えられるとコインがもらえ、3問ごとに英語ランクが上がります（Lv1 たまご → ひよこ → わかば → つぼみ → はなまる → ほし → にじ → Lv8 たいよう）。ランクが上がるほど、質問が少しずつ難しくなります（はい・いいえ → 好きなもの → ふだんのこと → きのうのこと → これからのこと → 理由 → 説明 → 「もし〜なら」）。

「日本語で見る」で質問の意味、「こたえ方のヒント」で答え方の例が見られます。答えたあとは、ほめことばと「こんな言い方もできます」というお手本が出ます。

きせかえショップ

右上の「きせかえ」から、自分のアバターを着せ替えられます。コインは、チャレンジで答える・レッスンで言える・ステージをクリアする・会話で話す、でたまります。

  • サロン：顔の輪郭・はだ・目の色・かみの色と、88通りの髪型（後ろ髪22種類 × 前髪4種類）。
  • 12のブランドのトップス・バッグ（リュックなど）・ぼうし・くびもと・めがね・ピアスで、全372アイテム。ブランドは、すべてこのアプリのオリジナル（架空）です。
  • アイテムをタップすると、買う前に鏡の前で試着できます。

ひろば（同じ事業所の人と会える）

「ひろば」タブでは、きせかえたアバターで、同じ事業所の人と会えます。行きたい場所をタップすると歩きます。

  • 話す：下の英語のことばやスタンプを押すと、アバターの吹き出しに出て、英語で読み上げられます。話せることばは決まった英語だけです。
  • おうえん：「いま、いる人」から「おうえん」を押すと、「Good job!」などが届きます。届いた人はコインがもらえます。
  • マイルーム：「もようがえ」で、コインで家具やかべ・ゆかを買って置けます。家具はドラッグで動かせます。ほかの人のおへやにも遊びに行けます。
  • いっしょにレッスン：同じ場所にいる人をさそうと、ふたりで質問と答えを交互に声に出して言い合います。さいごまでできると、ふたりともコインがもらえます。
  • 安心のために：名前は英語の組み合わせ（例：Happy Fox）から選ぶだけで、本名や連絡先は出ません。気になる人は「ミュート」で見えなくできます。
  • ひろばに入れないときは、事業所の方に「ひろば」の設定をお願いしてください。

ここまで保存・続きから

  • ここまで保存：レッスン中でも、止めているときでも、いつでも押せます。練習の途中で声で「セーブ」「保存」と言っても保存できます。
  • 次に開いたとき：同じスマホ・パソコンなら、マイクのボタンを押すだけで「前回の続き」から始まります（一時停止したときも、その場所を覚えています）。
  • つづきの合言葉：保存すると、8文字の合言葉（例：K7MP-Q3XA）が出ます。メモしておくと、別のスマホやパソコンでも、ブラウザの記録が消えてしまっても、「合言葉で続きから」に入れるだけで、進み具合・スター・復習リスト・声の登録・設定がそのまま戻ります。
  • 一度合言葉を作ると、そのあとは同じ合言葉に上書き保存されます。ステップをクリアしたときと一時停止したときも、自動で保存されます。
つづきの合言葉を知っている人は、だれでもあなたの進み具合を読み込めます（中身は練習の記録だけです）。人には教えないでください。

小さな声・にぎやかな場所

  • 声の登録：「声を登録する」を押すと、まず2秒間まわりの音を測り、そのあと「ハロー」と3回言ってもらいます。あなたの声の大きさと響きを覚えて、マイクの感度を自動で合わせます。ふだん練習で使う声（ささやき声ならささやき声）で登録してください。
  • まわりの音と分ける：アプリは、その場のまわりの音（エアコン、車、話し声のざわめき）を常に測り、それより目立つ「あなたの声」だけを話した声として扱います。登録した声と響きが違う音（食器の音、音楽など）は拾いにくくします。
  • 小さな声を持ち上げる：マイクの感度を上げ、送る前に聞き取りやすい大きさにそろえます。
近くで別の人がはっきり話していると、その声を拾うことがあります。声の登録は「声の大きさと響き」で見分ける簡易的なもので、人ひとりを確実に聞き分ける仕組みではありません。にぎやかな場所では、マイクつきイヤホンを使うのがいちばん確実です。ささやき声がうまく入らないときは、設定の「ブラウザの雑音カット」を「使わない」にしてみてください。

つっかえても大丈夫

  • 急かさない：話し始めるまで、いつまでも待ちます。話し終わりは「3秒だまったら」が基本です。途中で長く止まってしまう人は、設定の「話し終わりの合図」を 5秒・8秒、または「言い終わった」ボタンを押したらにしてください。ボタンにすると、どれだけ間があいても、途中で送られることはありません（パソコンは Enter でも送れます）。
  • 採点に入れない：音や言葉のくり返し、のばし、ことばが出ないあいだの沈黙、言い直しは、まちがいとして数えません。AIもそれについて何も言いません（設定の「つっかえ・沈黙への配慮」）。点数は発音・文法・語彙の3つだけになります。
  • 相手もせかさない：会話の相手は、あなたの文を先回りして言ったり、話し方について何か言ったりしません。相手が話しているあいだに声が入っても、相手の話をさえぎらないようになっています。
  • 困ったときのことば：STEP 3 で「Just a moment.（ちょっと待ってください）」を練習します。本番の英会話でも、考える時間をもらえる大事なひとことです。

話し相手の選び方（会話タブ）

レッスンに慣れたら、「会話」タブでAIとじっさいに話してみましょう。レベルが「はじめて」のときは、相手はとても簡単な英語で話し、こたえに困ったら日本語で「こう言えばいいよ」と教えてくれます。相手ごとに、話し方・声・性格が違います。

相手出身こんな人におすすめ
Emmaロンドンはじめての英会話。ゆっくり、はっきり話し、言葉に詰まっても待ってくれます。
Jakeサンディエゴくだけた日常英語やスラングに慣れたい人。元気でカジュアル。
Oliviaニューヨーク面接・会議・プレゼンなど、仕事で使うきちんとした英語の練習に。
Liamシドニー旅行や食べ物の話を気楽にしたい人。聞き上手で話を広げてくれます。
Graceトロント本・映画・考えごとを深く話したい中上級者。少し豊かな語彙を使います。

「場面」で、フリートーク・自己紹介・カフェで注文・面接・道案内などのロールプレイも選べます。

会話の流れ

1. 話す

マイクのボタン（または Space）を押すと、相手から話しかけてきます。話し終えて「話し終わりの合図」の時間だけ黙るか、「言い終わった」を押すと、相手が返事をします。相手の口は声に合わせて動き、話した内容は顔の下に字幕で出ます。いま読み上げている言葉にはオレンジのマーカーが引かれるので、どこを話しているかを目で追えます（お手本の読み上げや「▶聞く」でも同じです）。

2. 採点は裏で静かに

会話中は点数やアドバイスを表示しません。話した英語は裏で採点して集めておき、おさらいでまとめて見せます。ひとことごとに点数を見たい人は、設定の「会話中の採点」を「ひとことごとに表示する」に変えてください。

3. おさらい

終えたいときは 「That's all」「Let's review」「おさらい」と言うか、R を押します。会話中に集めておいた直すポイントがすぐに出て、そのまま言い直し練習に入ります。全体の感想とよかった点は、少しあとから書き足されます。

4. 言い直し練習

おさらいが終わると、そのままリピート練習が始まります。お手本を聞いたら、同じ文を言ってください。1つの文につき3回まで挑戦でき、言えたら次へ進みます。「Skip」で次の文へ、「Stop」で一時停止します。

音読と復習

音読タブでは、例文（または自分で入れた英文）を、お手本 → 音読 → 判定 の順に練習できます。

復習タブには、おさらいで出てきた表現がたまります。言えた表現は 1日後・3日後・1週間後… と間を空けて、言えなかった表現は早めにまた出ます。タブの数字は今日復習する件数です。

復習の記録は、使っている端末のブラウザの中に保存されます。別の端末やブラウザとは共有されません。

点数の見方

項目見ているところ
発音L/R、TH、V/B、母音を足してしまう癖（desuku など）、単語の強く読む位置
文法時制、冠詞、前置詞、語順など
語彙場面に合った自然な言葉選び
流暢途中の長い間、言い直し、つなぎ言葉の多さ（「つっかえ・沈黙への配慮」を「しない」にしたときだけ）
語/分1分あたりに話した語数。会話ではおよそ 100〜150 が目安です

点数は 10 点満点です。AIによる目安なので、日ごとの上下より、同じ指摘がくり返し出ていないかを見るのがおすすめです。画面右下の小さな棒グラフは、最近の総合点の推移です。

キー操作（パソコン）

  • Space：開始・一時停止（一時停止したところから再開できます）
  • Enter：言い終わった（話し終わりを知らせる）
  • R：おさらいを作る
  • N：レッスンや練習中の文をとばす
  • Esc：一時停止

設定

  • 利用コード：購入時に届いたコード（モニターの方は合言葉）。「確認」を押すと、有効期限と今日あと何回話せるかが表示されます。端末の中にだけ保存されます。
  • 話す速さ（相手の顔の下のつまみ）：相手の英語が速いと感じたら左へ。声の高さはそのままで、0.6倍〜1.2倍に変えられます。お手本の読み上げにも効きます。会話中に動かすとすぐ反映され、遅めにすると次の会話から相手も区切ってゆっくり話すようになります。
  • あなたのレベル：「はじめて」から「上級」まで。相手の話す速さや言葉の難しさ、採点の基準が変わります。
  • お手本の声：練習のお手本を読む声。相手を選ぶと、その人の国の声に自動で切り替わります。
  • 話し終わりの合図：何秒黙ったら話し終わりとみなすか。「言い終わった」ボタンにすると、時間では区切りません。
  • つっかえ・沈黙への配慮：「する」にすると、くり返し・のばし・沈黙・言い直しを採点に入れません。
  • ほめ方：大げさに（効果音・紙ふぶき・高い声）／ふつう／しずかに。
  • やさしいアドバイス：ほめたあとに「こうするともっと良くなりますね」を伝えるかどうか。
  • お手本といっしょに言う練習：レッスンで、ひとりで言う前に声を重ねる練習をはさむかどうか。
  • マイクの感度・登録した声だけ拾う・ブラウザの雑音カット：小さな声やにぎやかな場所のための設定です。声の登録をすると感度は自動で合わせます。
  • 日本語のアドバイス：練習中のアドバイスを読み上げるか、表示だけにするか。

困ったとき

マイクが使えない・反応しない

アドレスバー左のアイコンからマイクを「許可」にして、ページを再読み込みしてください。ほかのアプリ（会議アプリなど）がマイクを使っていると反応しないことがあります。

相手が勝手に話し出す・会話が途切れる

スピーカーの音をマイクが拾っています。イヤホンを使ってください。

相手の英語が速くて聞き取れない

相手の顔の下にある「話す速さ」のつまみを左に動かしてください。設定でレベルを「初級」にし、Emma を選ぶと、さらにゆっくり、やさしい言葉で話します。字幕も合わせて見てください。

話している途中で送られてしまう

設定の「話し終わりの合図」を 5秒・8秒にするか、「言い終わった」ボタンを押したら、にしてください。

小さな声が聞き取ってもらえない

「声を登録する」をやり直してください（ふだん練習で使う声で）。それでも入らないときは、設定の「マイクの感度」を上げるか、「ブラウザの雑音カット」を「使わない」に。マイクつきイヤホンがいちばん確実です。

話していないのに、話したことになる

まわりの音が大きく変わったときに起こります。少し静かにしていると、アプリがまわりの音を測り直します。声を登録し、「登録した声だけ拾う」を「拾う」にしてください。

「AIが混み合っています」と出る

AI側が混雑しています。アプリが自動でやり直しますが、続く場合は少し時間を置いてください。会話の内容は残っているので、「おさらいへ」でもう一度作れます。

「今日の回数が上限に達しました」と出る

1日に使える回数の上限です。日本時間の0時にリセットされます。

「利用コードが見つかりません」と出る

設定を開いて、届いたコードを入れ直してください。小文字やハイフンなしで入れても大丈夫です。数字の0とアルファベットのO、1とIは使っていません。

「利用期限が切れました」と出る

プランの期間が終わっています。延長や再購入は、ご購入いただいた窓口からお問い合わせください。

スマホで使える？

使えます。画面を開いたままにしてください（画面が消えると会話が止まります）。

音声データについて

話した音声と文字起こしは、会話の返事と採点を作るために Google の Gemini API に送られます。Gemini API の無料枠で運営している間は、送られた内容が Google のサービス改善に使われることがあります。

アプリ運営者のサーバーには、おさらいを作る間の一時的なデータ（受け取りしだい削除）を除いて、会話の内容を保存しません。復習リストや点数の記録は、お使いの端末のブラウザの中にだけ保存されます。
